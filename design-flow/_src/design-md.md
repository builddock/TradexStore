## Brand & Style

This design system delivers a high-performance, dark-mode commerce environment designed for tech enthusiasts, hardware connoisseurs, and IT professionals. The visual tone balances industrial engineering with luminous digital polish: razor-sharp, low-friction, and immersive. 

The aesthetic synthesizes **minimalist precision** with **cyber-industrial accenting**: deep, non-reflective obsidian surfaces, crisp 1px delineation lines, and disciplined neon illumination. Electric cyan and cobalt-violet glows are used strictly as functional signalsâ€”guiding purchase decisions, emphasizing performance tiers, and clarifying specifications rather than decorative noise. 

The emotional response is calculated, elite, and frictionless. Users should feel like they are interfacing with a mission-critical hardware configurator rather than a conventional online catalog.

## Colors

The palette establishes an obsidian continuum:
- **Base Canvas:** `#0B0F17` (Deep Obsidian) serves as the primary canvas, creating an infinite, low-glare depth.
- **Surface Layer 1:** `#131B26` (Matte Slate) builds card shells, inputs, and container panels.
- **Surface Layer 2:** `#1B2636` (Elevated Slate) provides hover states and modal backdrops.
- **Structural Borders:** `#1F2937` (Subtle Rim) for passive borders; `#374151` (Active Rim) for active/hover outlines.
- **Primary Brand Ray:** `#00F0FF` (Electric Cyan) drives primary calls-to-action, key feature highlights, and active states.
- **Secondary Accent:** `#6366F1` (Neon Cobalt/Violet) handles telemetry badges, category grouping, and secondary highlights.
- **Tertiary Utility:** `#10B981` (Laser Emerald) signals stock availability, success confirmations, and checkout validation.
- **Text & Foreground:** High-contrast legibility reigns with `#F9FAFB` for primary headlines/data, `#9CA3AF` for auxiliary copy, and `#4B5563` for muted captions.

## Typography

The type system implements a tripartite hierarchy:
1. **Space Grotesk** commands marketing, category headlines, and product titling. Its geometric, slightly mechanical forms establish an authentic tech identity.
2. **Inter** handles narrative descriptions, UI controls, reviews, and body text, prioritizing maximum optical clarity on dark backgrounds.
3. **JetBrains Mono** governs the transactional layer: tech specs, SKU codes, latency/wattage statistics, inventory counts, and price tags.

All mono labels apply uppercase styling with expanded letter-spacing to reinforce technical precision.

## Layout & Spacing

The layout is anchored by a structured 12-column responsive fluid grid on desktop (max container width: 1440px), transitioning to an 8-column layout on tablets, and a 4-column layout on mobile devices.

- **Desktop (>= 1024px):** 12 columns, `1.5rem` gutters, `2rem` margins. E-commerce catalogues follow a 3-column or 4-column card rhythm.
- **Tablet (768px - 1023px):** 8 columns, `1.25rem` gutters, `1.5rem` margins. Product lists collapse to a balanced 2-column configuration.
- **Mobile (< 768px):** 4 columns, `1rem` gutters, `1rem` margins. Product listings feature alternating 2-column compact grids or stacked 1-column detail views. Touch targets maintain a minimum vertical height of 48px.

## Elevation & Depth

Visual hierarchy uses a hybrid system of **tonal stepping**, **subtle hairline borders**, and **localized neon edge illumination**:

- **Ground Level (Elevation 0):** Background `#0B0F17`.
- **Card Surface (Elevation 1):** Solid `#131B26` with a uniform `1px solid #1F2937` perimeter. No heavy drop-shadows; separation is strictly chromatic.
- **Floating Controls & Modals (Elevation 2):** `#1B2636` with a border of `1px solid #374151` and an ambient shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.65)`.
- **Interactive State (Glow Elevation):** Hovered product cards, active filter tags, and primary CTAs project a calibrated glow: `0 0 16px -2px rgba(0, 240, 255, 0.22)` or `0 0 16px -2px rgba(99, 102, 241, 0.25)`.

## Shapes

The interface embraces a disciplined **Soft (Level 1)** geometry, projecting industrial precision rather than consumer playfulness:
- Standard buttons, badges, input fields, and chips utilize `0.25rem` (4px).
- Product cards, flyout drawers, and banners utilize `0.5rem` (8px, `rounded-lg`).
- Large overlay modals utilize `0.75rem` (12px, `rounded-xl`).
- High-contrast technical badges (e.g., status tags) maintain sharp 2px corners or strict `0.25rem` bounds; pill or circular shapes are reserved exclusively for circular iconography, product color swatches, and notification counters.

## Components

### Buttons
- **Primary:** Background `#00F0FF`, text `#0B0F17` (bold `Space Grotesk`), border `none`. Hover initiates a dynamic outer aura `box-shadow: 0 0 20px rgba(0, 240, 255, 0.45)`.
- **Secondary:** Surface `#131B26`, text `#F9FAFB`, border `1px solid #374151`. Hover shifts border to `#6366F1` with text `#6366F1`.
- **Ghost/Tertiary:** Transparent base, text `#9CA3AF`, hover background `rgba(255, 255, 255, 0.05)`.
- **Cart/Checkout:** Fixed full-width bottom bar on mobile with embedded JetBrains Mono total price on the left and quick-purchase trigger on the right.

### Product Cards
- Built on `#131B26` with `1px solid #1F2937` borders.
- Top section holds an image container on a neutral `#0F1621` background, equipped with an absolute-positioned top-left discount/status pill.
- Body contains category tag (`label-sm`, `#9CA3AF`), product title (`Space Grotesk`, `headline-sm`), key specification matrix (`JetBrains Mono`, `body-sm`), and cyan-accented pricing lockup.
- Hover action triggers a smooth transition to border `#374151` and cyan ambient bottom-border glow.

### Specs & Discount Badges
- **Discount:** `#6366F1` with 15% opacity background, `1px solid #6366F1`, text `#FFFFFF`, mono uppercase.
- **Stock Alert:** `#10B981` with 15% opacity background, text `#10B981`, leading 6px pulsing dot.
- **Spec Pill:** Solid `#0B0F17` background, `1px solid #1F2937`, text `#9CA3AF`, displaying hardware metrics (e.g., `32GB DDR5`, `2.4GHz`, `0.2ms`).

### Input Fields & Search
- Background `#0B0F17`, border `1px solid #1F2937`, text `#F9FAFB`. 
- Focus state shifts border directly to `#00F0FF` with a subtle inner glow `box-shadow: inset 0 0 4px rgba(0, 240, 255, 0.2)`.
- Global search bar incorporates a quick-command keyboard shortcut badge (`JetBrains Mono`, `âŒ˜K`) on desktop.

### Checkboxes & Radios
- Square checkbox elements with `2px` corner radius.
- Unchecked: `1px solid #374151` on `#0B0F17`.
- Checked: Fill `#00F0FF` with `#0B0F17` checkmark.
- Radio buttons follow standard concentric rings with a `#00F0FF` active core.

### Technical Data Lists
- Alternating subtle row fills (`#131B26` and `#0E141E`).
- Strict column alignment with divider lines `1px solid #1F2937`.
- Left label in muted Inter (`#9CA3AF`), right value aligned in JetBrains Mono (`#F9FAFB`).
