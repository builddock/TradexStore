Definitions used in this report

Version 1.2 · approved by Finance · history
Gross vs net sales
Gross = tax-invoice line value after line discounts, before returns. Net = gross − credit notes (returns & refunds) issued in the period. Shipping recovery and payment fees are excluded.
Order vs invoice vs dispatch dates
Each event has its own date; the filter row chooses the basis. This view uses invoice date.
OrderPaymentInvoiceDispatchSettlement
Refunds in a later period
Counted when the credit note is issued, not against the original sale. ₹1.12 L of this period’s returns relate to August invoices.
Tax-inclusive / exclusive
Figures are excl. GST unless toggled; GST is shown separately. Storefront consumer prices are GST-inclusive, dealer prices ex-GST. GST is computed per line (5% / 12% / 18%), not a flat rate.
Exclusions
Test orders, orders cancelled before invoicing and inter-branch transfers are excluded. Not a statutory profit & loss statement.

How exports work

Applies to every report and scheduled file
  • Row limit: up to 50,000 rows per direct download. Larger extracts run as a background job so they cannot slow checkout, and arrive as a link.
  • Expiring links: downloads are private to the requester and expire after 24 h (external accountant: 7 days + OTP).
  • Formula-injection safe: text cells starting with = + - @ or tab/CR are prefixed with ' so spreadsheets never run them. Example: a customer name =HYPERLINK(…) exports as '=HYPERLINK(…).
  • Plain values: amounts in INR without symbols, dates as ISO 8601 (IST), tax basis in the file header.
  • Permissions: personal data, supplier cost and margin columns need the matching permission; every export is logged with filters and row count in the audit trail.
