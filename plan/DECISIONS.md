## How to record a decision
1. Change the row's **Status** to `DECIDED` and fill **Decision** with `value · approver · YYYY-MM-DD`.
2. Add a line to `STATE.md` → *Decisions log*.
3. In `TASKS.md`, move tasks whose only blocker was this decision from `REQUIRES_DECISION` to `NOT_STARTED`.
4. If the decision changes a plan file (e.g. D-001 fixes the platform), update that file and note it in the
   session log. Do not rewrite unrelated sections.
