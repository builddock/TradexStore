Configurable Root Admin

The control plane of the SaaS commerce platform. It is where a store is created, given an e-commerce category, given a site template, branded, feature-configured and deployed. It is a separate portal on a separate codebase with its own database and its own sign-in — no store user ever reaches it, and no store page links to it.

How the two platforms fit together

This platform

Holds the authoritative configuration of every store in its own database, compiles it into an immutable, versioned artefact, and publishes it. Operators work here; store users never do.

Codebase
root-admin/
Database
Its own — no connection to a store database
Sign-in
Separate realm, multi-factor mandatory
Dependency
One way: platform → artefact → store

The store platform

One codebase serving every store. At boot it loads the artefact into memory and reads nothing from a database for configuration afterwards, so configuration costs nothing per request.
