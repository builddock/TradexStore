Per-client separation

7 of 7 stores separated

Each client has its own database, its own image container with its own credentials, its own search index and its own cache namespace. Nothing is shared between clients. Every record also carries its store identifier, so an operational mistake — a wrong connection, a restore into the wrong place — still cannot mix two clients' data.

Certificates

Certificates are requested and renewed automatically. A renewal that fails raises an alert 14 days before expiry, not on the day. An address the platform does not recognise returns a plain page that names nothing.

Alerts

Every alert has a named owner. Only the ones that affect a live store's customers wake somebody; the rest are reviewed once a day.

Release notes

A new store platform release brings new features and new settings. Existing stores keep their configuration exactly as it is; new settings take their default until someone changes them.

If a release changes the configuration format, every published configuration is rebuilt and compared before the release is allowed out.
