Bundles

The reusable building blocks a category is assembled from. Author the hard thinking once — what a perishable business needs, what a trade business needs — then apply it to any category instead of making the same forty decisions again and getting a different answer each time.

A category is assembled as base + bundles (in the order you choose) + category-specific changes. Two bundles asking for incompatible things is an error you resolve, never something the system decides quietly. Nothing about bundles ever reaches a store — a store only receives the finished configuration.

New bundle

A bundle may only use features that exist in the platform release. If it needs something new, that is one change to the system — and every category gets it afterwards.
