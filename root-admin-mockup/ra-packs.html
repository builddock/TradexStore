E-commerce categories

A category decides what a store can do: its product structure, how stock is identified, which features start on, and the words everyone sees. It is configuration and starting content — never code — so categories can be added, updated and retired without a new application.

Category catalogue

What a category contains

Structure
Category tree · product attributes and their units · variant axes · search filters · how a stock unit is identified · units of measure
Behaviour
Which features start on or off · pricing model · delivery models · return and exchange policy classes · which features the store may change
Presentation and words
Storefront section set · workspace screens, tabs and columns · supplier submission fields · the complete wording set per language
A category never contains program code. Publishing a new version of a category changes no existing store: a store moves only when someone runs a migration and accepts the preview of what would change.
