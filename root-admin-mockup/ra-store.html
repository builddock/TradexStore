Other placements available

Dedicated runtime

This store gets its own processes and hosts, still managed from here. For performance isolation or a separate release cadence.

Standalone install on the client's own server

The same unchanged system runs on the client's infrastructure, in their region. It serves traffic with no connection to this platform; configuration arrives as a signed file or a signed download, bound to this store and its addresses. Version skew is limited to one release.

Shared database

Several stores in one database. Available for internal and demonstration use, or where a client has explicitly agreed to it — never applied silently.

Environments

Promote staging → production

Copies the values of a published staging configuration into the production draft. It then goes through the usual checks and difference review before anything is published.

Never copied: addresses and certificates, credentials, the store's own settings, the features the store switched itself, users, or any business data.

Configuration versions

Versions are never edited or deleted. Going back is publishing an earlier version again, which takes the same few seconds as going forward.

Deployments

All runs
These are the store's own people. They belong to this store only; their sign-in works on no other store and not on this platform. Read-only here — the store manages its own staff.

Support access

Nobody on this platform can see this store's data without an approved, time-limited grant. The store owner is told when one starts, and every action appears in the store's own audit trail with the platform user's name.

Platform actions on this store

Suspend the store

The storefront shows a short notice in the store's own branding, no orders can be placed and nothing is deleted. Reversible at any time.

Archive the store

Stops serving entirely and keeps the data for the retention period. Reversible during retention.

Export everything for this client

A complete, documented export: business data, the store's own settings and the features it switched, its configuration and its images. Used for portability, end of contract or a legal request.

Decommission and destroy data

Permanent. Requires a second platform owner to approve, offers the owner an export first, waits out the retention period and records destruction evidence.
